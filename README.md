# Vista

Dashboard crypto semplice: prezzi live, grafici, indicatori. Mobile-first, un solo file.

**Live:** https://richy77-tech.github.io/vista/

- Top 25 crypto per capitalizzazione, prezzo e variazione 24h
- Sparkline 7 giorni per ogni riga
- Dettaglio con grafico 24H / 7G / 30G / 1A
- Indicatori: media 7, media 30, RSI 14
- News crypto (Cointelegraph, Decrypt)

Dati da [CoinGecko](https://www.coingecko.com) e feed RSS pubblici. Nessuna chiave richiesta.
Non è consulenza finanziaria.
